# 动效说明

第 3 批（M-01 到 M-06）用。静态版（第 2 批）不需要这里的内容，每屏只做 `screens/` 里那一帧。

## 通用规则

- **每屏一个场景模块。** 外层的高度是若干个屏高，里面一层用 CSS `position: sticky` 固定在屏幕上。滚动进度 `p` 从 0 到 1。
- **GSAP + ScrollTrigger 只负责把这一屏的时间线绑到 `p`**（`scrub`），不用它的 `pin`。
- **退路。** 手机，或系统开了「减少动态效果」时：不加载 GSAP，每屏显示静态帧。有两拍的第 3 屏把两拍上下排开。
- **声音。** 默认关。用户点了左下角圆点之后才开；开着的时候，板落位、换层、句号落地各响一声「叮」。声音是代码合成的，做法在小样里（`initAudio`、`clink`）。
- **数字。** 计数块里的数字滚动变化，值从 `wall/tiles.json` 的数据里算，不手写。
- **页头。** 背后是图片墙的屏（第 2、3 屏）切到胶囊样式，其余用普通样式。

## 02 出素材：铺满

| 进度 | 画面 |
|---|---|
小样已经实现：`motion/wall-prototype/index.html`（原生脚本，用浏览器直接打开，往下滚或点底部的「自动播放」）。

| 进度 | 画面 |
|---|---|
| 0 → 0.1 | 深色底上只有母版一张，在屏幕正中，比它在墙里的位置大约 24%。计数块显示 1、1 种语言、1 种尺寸 |
| 0 → 0.24 | 母版缩回原大，移到它在墙里的位置（434, 170） |
| 0.1 → 0.92 | 其余 39 张从母版背后飞出来。先落到母版附近的先出发，最远的最后出发；每张用进度的 0.30 飞完。起点在母版中心、镜头后方约 950px 处，带一点随机的倾斜；一路减速，飞到自己在墙里的位置并转正。计数只在一张真正露面时才加 1，「种语言」「种尺寸」跟着涨到 7 和 4 |
| 0.92 → 1 | 停住。画面和 `screens/02-wall.html` 完全一样 |

- **四层纵深。** 飞行途中每张会朝镜头荡出一段再回到墙面：十分之三不荡，十分之三荡 90px，十分之二荡 240px，十分之二荡 520px。荡得最远的那几张会放得很大、从镜头前掠过。
- **景深。** 离墙面超过约 70px 的卡片按距离加模糊，上限 12px。落到墙面时必须完全清晰。
- **每次播放都一样。** 出发顺序、倾斜角度、荡多远都由卡片的序号算出来，不用真随机。小样里是 `rnd(i)`。
- **只借纵深和运动。** 不要做成球形的卡片云，不要加渐变色团和虚线轨道。
- **性能。** 模糊是最贵的部分：只在数值变化超过 0.4px 时更新；同一时刻在飞的卡片不超过十几张。实现时如果掉帧，先把模糊档位量化成 0、4、8、12 四档，再考虑别的。
- **退路。** 手机、微信内置浏览器、「减少动态效果」：不做这段动画，直接显示落定后的墙。
- **移植。** 小样用原生脚本读滚动位置；实现时按通用规则改成 GSAP 时间线绑进度，卡片的参数照小样里的公式。
- 静态帧（结束状态）：`screens/02-wall.html`。
- 这一屏只出现广告图片，不出现达人视频。

## 04 达人：一条流

| 进度 | 画面 |

- 静态帧：`screens/04-creators.html`（直接打开会自动播放；封面是静止时的样子）。

### 中间那条是真视频

- 文件：`assets/video/creator-pebble.webm` 和 `assets/video/creator-pebble.mp4`，768×1344，8 秒，24 帧，没有声轨。封面是 `assets/img/ugc_pebble.jpg`（视频第 3.5 秒那一帧）。
- 内容：前 4 秒她举着打开的耳机盒，耳朵上没有耳机；第 4 秒切镜头；后 4 秒两只耳机戴在耳朵上，画面里没有盒子。循环播放，从结尾跳回开头是硬切，不用做过渡。
- 它是 AI 生成的示例内容，人物和产品都是虚构的。**「示例内容」的标注必须保留**，直到换成真实达人的视频。
- 播放规则：`muted`、`loop`、`playsinline`，不显示控制条，永远不出声。屏幕进入视口再加载和播放（`preload="none"` 加 IntersectionObserver），离开视口就暂停。
- 静态版（第 2 批）也播放这条视频：进入视口后直接从头播，不需要 GSAP。
- 退路：
  1. 系统开了「减少动态效果」：不播放，只显示封面图。
  2. 手机：先只显示封面图。等手机稿定了再决定播不播。
  3. 视频加载失败：显示封面图。做法是 `<video>` 下面垫一张同样大小的 `<img>`，`screens/04-creators.html` 里就是这么写的。
- 两侧的四列还是静态图，不换成视频：省流量，也不抢中间那条的注意力。
- 页面叠在视频上的三样东西是：左上的贴纸、左下的账号名、右下角的句号。视频里人脸和产品都避开了这三处。用 `object-fit: cover` 居中裁切，不要改 `object-position`。
