# ClinkAI 官网设计交接包

导出日期：2026-11-27。来源是设计画布上「新节奏」那一排（6 屏，其中第 3 屏有两拍）和 3 个子页面。

**设计和文案以这个文件夹为准。** 实现时发现问题，在 Issue 里报，由设计侧改这里；不要在代码里自己改设计或文案。

## 这次按什么定稿

下面三条是设计侧的判断，用户还没有逐条确认。用户改主意时，这个文件夹会更新，改动记在文末「变更记录」。

1. 首页用「新节奏」这一排。更早的那一排（策略品牌、扇形广告、内容与结论各占一屏）不做。
2. 首屏用加厚背景的版本：叠板放大、背景有光和颗粒、图例用细线连到板上。
3. 主标题保持英文，中文说明放在旁边。

## 三条容易踩的排版规则

1. **英文大标题用纯拉丁字体栈**（`tokens.css` 里的 `--font-latin`）。页面语言是中文，字体没加载完时，弯引号会被中文字体渲染成全角，`LET’S` 中间会裂开一个大空。
2. **中日韩标题只在词和词之间换行。** `screens` 里把每个词包成了 `inline-block`，移植时保留这个做法。
3. **版本墙里压在页头胶囊下面的小图不放标题，或者把标题放到胶囊下方。** 数据里已经处理好了，改版面时别破坏。

## 参考截图的局限

`refs/*.jpg` 是在没有 Inter Tight 的环境里渲染的，拉丁字母用 Inter 代替，字宽比真实效果略大；中文用的是 Noto Sans CJK。布局、颜色、图片位置是准的，文字的精确宽度不准。P-07 做截图对比时，请用自托管的字体从 `screens/*.html` 重新渲染一套作为基准，不要直接拿这里的图做像素对比。

## 还没做的和已知问题

1. **没有手机稿。** 现在只有 1440 宽的桌面稿，P-02 被它卡住。
2. **【待填】没补。** 清单在 `copy.md` 末尾。
3. **首屏小样还是旧样子**：旧背景、板没放大、图例没有连线。动法以小样为准，静态样子以 `screens/01-hero.html` 为准。
4. **第 2 屏的进场动画没有静态稿，只有小样**（`motion/wall-prototype/`）。原来设想的「扇开四张」不做了。
5. **首屏叠板上的示例图来自四个虚构品牌**（Halfmile、Acme Charge、Dewlab、Dawnroast），首页后面几屏只讲 Pebblesound 一个产品。这是有意的：首屏讲服务范围，后面讲一个产品从出素材、测试到达人的过程。产品页的 ClinkAI Ads 那一屏相反，用七个不同的产品（用户要的，为了丰富），不出现耳机；ClinkAI Creators 那一屏的品牌仍是 Pebblesound。
6. **各语言的示例标题和达人账号名是设计侧编的。** 上线前标题找母语的人看，账号名逐个查有没有撞到真人。
7. **所有示例图片和视频都是 AI 生成的**，品牌虚构，人物也是虚构的。
8. **达人示例视频里，戴在耳朵上的耳机带一点短柄，和盒子里无柄的造型不完全一样。** 耳机在画面里很小，设计侧判断可以接受；换成真实达人视频时这个问题自然消失。
9. **达人屏两侧的四列是静态图**，只有中间那条是视频。
10. **产品页的星图是示意。** ClinkAI Creators 产品里实际是表格，没有这张图；文案还写着「在一张表里看清」，要不要改等用户定。轨道上没写名字的小点不代表具体数量。
11. **产品页第 1、2 屏没有设计动效**，只有第 3 屏有小样。第 2 屏的「一圈」以后可能做成慢慢转的，现在按静态做。
12. **关于我们右边六行里，03 广告、04 达人两行的说明是设计侧新写的**，等用户确认。
13. **子页面的三屏和关于我们用户还没有逐屏确认**，尤其是产品页第 2 屏（11-28 下午改过四次：换产品、换成七个产品、去掉底下三步的字、去掉右上角的一句话介绍）。
